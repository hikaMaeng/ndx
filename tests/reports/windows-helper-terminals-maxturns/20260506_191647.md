# Windows Helper Terminals And Max Turns - 2026-05-06 19:16:47

## Change Under Test

- Child processes spawned by ndx should not open helper terminal windows on
  Windows.
- A turn that reaches `maxTurns` should warn that it stopped before a final
  answer and should not print partial model text from a tool-call response.

## Expected Result

- Managed process execution, Docker sandbox commands, and generated core tools
  use `windowsHide: true`.
- `agent stopped after max_turns=...` clearly says no final answer was produced
  and the request may be incomplete.
- Partial text that accompanies tool calls is kept in conversation context only;
  it is not emitted as a final answer.
