# Runtime Skill Tool Report

## Changes Under Test

- Added built-in `list_skills` and `load_skill` task tools.
- Updated available-skill instructions so models load skill bodies with
  `load_skill` instead of shelling into `SKILL.md` host paths.
- Marked `request_user_input` as unavailable in this non-interactive runtime.
- Documented skill tool behavior and bumped the package to `0.1.33`.
