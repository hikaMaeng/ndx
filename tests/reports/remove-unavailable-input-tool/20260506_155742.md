# Remove Unavailable Input Tool Exposure - 2026-05-06 15:57:42

## Change Under Test

- Removed `request_user_input` from model-facing built-in task tools.
- Kept host-side skill tools available through `list_skills` and `load_skill`.
- Updated API and testing docs to describe the non-interactive schema contract.

- Real sessions cannot call `request_user_input`, avoiding the unavailable-tool
  loop seen in Windows CLI runs.
- Skill-aware turns can still inspect skill metadata and load `SKILL.md` bodies
  through host runtime tools instead of sandbox shell path guesses.
